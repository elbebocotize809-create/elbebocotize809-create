- **Never invent** — if the system doesn't know, it says so. Verified knowledge or honest abstention.
- **Proposal ≠ execution** — intelligence proposes; governance authorizes; everything is audited.
- **Security by design** — signed assertions, single-use nonces, fail-closed everywhere.
